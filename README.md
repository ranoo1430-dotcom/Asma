# منصة أثر برامج الخطة التشغيلية

مشروع جاهز للنشر على Netlify باستخدام React Vite.

## النشر السريع عبر Netlify
1. فكي ضغط الملف.
2. ارفعي مجلد المشروع إلى مستودع GitHub جديد.
3. في Netlify اختاري Add new site -> Import an existing project.
4. اربطي مستودع GitHub.
5. اجعلي Build command: `npm run build` و Publish directory: `dist`.
6. اضغطي Deploy، ثم انسخي رابط `netlify.app` الناتج وشاركيه مع المعلمات.
